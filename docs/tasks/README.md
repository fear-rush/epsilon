# Tasks

Work not done yet, one file per item. Take one at a time. Something else you notice
becomes a new file here, not part of the current commit.

A task file is deleted in the commit that finishes it.

```markdown
# <what is wrong or missing, as a sentence>

Do: …
Don't: …
Done when: <a command, a file state or a screenshot>
Stop and ask when: …
```
