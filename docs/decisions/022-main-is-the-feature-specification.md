# `main` is the feature specification

**Decision**

Every feature, screen, word, animation and test of `main` at `48226bb` is ported 1:1. What may differ is a closed list: the data source, the schema language, file boundaries, render performance and the feedback system. Dropping or changing anything else needs the owner's dated yes in the ledger. The app runs after every commit.

**Why**

The rebuild is a better foundation for the same product, not a new product. A rewrite from a description loses whatever the description left out.

**Rejected**

Rebuilding screens from the plan's prose; "the app runs at the end".
