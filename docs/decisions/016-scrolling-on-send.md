# Scrolling on send

**Decision**

Sending scrolls your message to the top of the view. While that anchor is active, the transcript does not follow new output; it resumes following once you scroll to the end.

**Why**

The operator's own message is the reference point for the turn, and following output fights reading it. Cost accepted: some output arrives off-screen while the anchor is held.

**Rejected**

"Always follow output", which was offered and declined.
