# Notes

A note records a trap that cost time. Write a note when a check fails for an
unexpected reason, or when a workaround outlives its fix.

## Format

Name the file `YYYY-MM-DD-short-slug.md`. Use four sections:

1. **Symptom**: what you saw.
2. **Cause**: what produced it, after you found out.
3. **Fix**: what removed it.
4. **Check**: the command or step that proves the fix.

Keep a note under one page. Remove a note when the code makes the trap impossible.
